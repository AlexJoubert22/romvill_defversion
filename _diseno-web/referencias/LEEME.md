# Referencias

Material de apoyo para diseñar: capturas de sitios que sirven de referencia,
auditorías del sitio actual, paletas, muestras tipográficas.

Ahora mismo está vacía.

Es el sitio para dejar **lo que justifica una decisión** de diseño, no los
archivos de trabajo de una propuesta concreta —esos van dentro de su propia
carpeta en `propuestas/`.

Ojo con el peso: las capturas de página completa ocupan varios MB cada una. Las
carpetas `capturas/` y los `.zip` están fuera del control de versiones a
propósito.
